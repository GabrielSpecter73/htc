1. O que é

O Almanaque Hub é uma ferramenta interna, de uso pessoal, que Gabriel Freitas de Oliveira usa no próprio computador para publicar os vídeos do próprio canal do YouTube "O Almanaque de Gåbriel Oliveira". Ela não é vendida, distribuída nem oferecida a outras pessoas.

2. Serviços de API do YouTube

A ferramenta usa os Serviços de API do YouTube (YouTube API Services). Quem usa a ferramenta concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

3. Uso permitido

A ferramenta só pode ser usada pelo dono do canal, com a conta Google dele, para gerenciar os vídeos do próprio canal: enviar vídeos como privados, preencher título, descrição, tags, idioma, miniatura e playlists, e agendar ou publicar depois da revisão no YouTube Studio.

4. Dados

O tratamento de dados segue a Política de Privacidade do Almanaque Hub. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
