O que é o Almanaque Hub

O Almanaque Hub é uma ferramenta interna, de uso pessoal, que Gabriel Freitas de Oliveira usa no próprio computador para gerenciar o canal do YouTube "O Almanaque de Gåbriel Oliveira" (youtube.com/channel/UCy_lucARZoMONXI9nPQUE-g). Ela não é oferecida a outras pessoas e não tem usuários além do dono do canal.

Dados acessados pela YouTube Data API

Com a autorização do dono do canal (OAuth), a ferramenta acessa somente o próprio canal dele: lista e status dos vídeos do canal, envio de vídeos do próprio canal como privados, título, descrição, tags, idioma, miniatura, playlists e agendamento de publicação. Ela não acessa dados de outros usuários, comentários, inscritos nem dados de outros canais.

Como os dados são guardados

O token de acesso fica só no computador do dono do canal, num arquivo com acesso restrito ao usuário dele. Nenhum dado do YouTube é enviado a servidores de terceiros, vendido, compartilhado ou usado para publicidade.

Como revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, a ferramenta deixa de acessar o canal e o token local pode ser apagado.

Serviços do Google

A ferramenta usa os Serviços de API do YouTube. Valem também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

English summary

Almanaque Hub is an internal, single-user tool that the channel owner (Gabriel Freitas de Oliveira) runs on his own computer to manage his own YouTube channel "O Almanaque de Gåbriel Oliveira". With the owner's OAuth authorization it only accesses that channel: listing its videos and their status, uploading the owner's own videos as private, and setting title, description, tags, language, thumbnail, playlists and scheduled publication. It does not access other users' data, comments, subscribers or other channels. The access token is stored only on the owner's computer; no YouTube data is sent to third-party servers, sold, shared or used for advertising. Access can be revoked at any time at myaccount.google.com/permissions, and the local token can be deleted. This tool uses YouTube API Services; the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy) apply.
