Almanaque Hub

O Almanaque Hub é a ferramenta interna do canal do YouTube O Almanaque de Gåbriel Oliveira. Ela roda só no computador do dono do canal e usa os Serviços de API do YouTube (YouTube API Services) para publicar os vídeos do próprio canal: envio como privado, título, descrição, tags, miniatura, playlists e agendamento.

Política de Privacidade · Termos de Uso
